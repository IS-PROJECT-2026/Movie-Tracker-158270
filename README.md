# Marquee — Watchlist Tracker

A static movie/show watchlist app. Add titles, mark them watched, rate with stars, filter by status, and search — all persisted locally via `localStorage`. No backend required, deployed via GitHub Pages.

## Run locally
Just open `index.html` in a browser, or serve the folder with any static server.

## Features
- Add movies/shows with genre and type
- Mark watched / unwatched
- 5-star rating
- Search and status filtering
